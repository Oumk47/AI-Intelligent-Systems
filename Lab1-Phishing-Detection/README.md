# M115 Lab 1 – Phishing URL Detection

## Overview
This lab focuses on detecting phishing URLs using Machine Learning techniques.

## Dataset
PhiUSIIL Phishing URL Dataset (Kaggle).

## Methods
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Logistic Regression with different regularization techniques
- Model evaluation
- SHAP explainability
- Decision threshold analysis

## Files
- M115 Lab 1 notebook (`.ipynb`): Complete code, analysis, results, and visualizations.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SHAP.
